# JBang, un fichier Java pour les gouverner tous ? 💍

**Stéphane Philippart — Vendredi 7 novembre 2025 — Salle 4 (D1+D2)**

## État de la transcription

**Carnet partiel : l'introduction et le début de la démonstration sont disponibles.** Le fichier se termine au milieu de l'explication du lancement d'un fichier exécutable. Il ne contient pas la suite des exemples ni la conclusion.

## Le coût d'installation d'un petit programme Java

Stéphane Philippart commence par un Hello World créé avec Maven. La génération prépare un répertoire de projet, un pom.xml, des tests et la structure nécessaire autour de quelques lignes de code. Il lance ensuite le programme avec le goal exec:java.

Le contraste sert à poser le besoin : pour de petits scripts ou des démonstrations, le cadre habituel d'un projet peut demander beaucoup de préparation par rapport au code utile. Le propos n'est pas de supprimer Maven de tous les projets, mais d'explorer une autre manière d'utiliser Java pour ce type de tâche.

## Faire du scripting avec Java

L'intervenant explique qu'il aimerait disposer d'un usage de script comparable à ce que permettent d'autres langages. JBang est présenté comme une réponse à ce besoin, avec la possibilité d'exécuter des scripts Java et de travailler sur de petits programmes sans commencer par tout le squelette montré auparavant.

Il annonce une présentation centrée sur le code. Les interfaces en ligne de commande sont évoquées, mais il précise ne pas être convaincu que tous les usages de CLI constituent le meilleur terrain pour cet outil. L'extrait ne contient pas encore les arguments développés derrière cette réserve.

## Installer l'outil puis repartir d'un fichier

Plusieurs modes d'installation sont cités, notamment Homebrew et SDKMAN. Pour la démonstration, Stéphane utilise SDKMAN, Java 25 et JBang. Ces versions décrivent l'environnement du talk, pas un prérequis universel à reprendre tel quel.

Il revient ensuite au Hello World, cette fois à partir d'un fichier Java. Le parcours doit montrer comment réduire la préparation avant l'exécution. Le début de l'exemple aborde notamment la possibilité de rendre ce fichier directement exécutable sur des systèmes de type Unix.

## Un en-tête pour lancer le bon outil

Stéphane introduit le mécanisme du shebang : un en-tête particulier indique comment exécuter le fichier. Il montre aussi le droit d'exécution associé au fichier. La transcription s'interrompt au moment où il explique ce que déclenche la première ligne au lancement.

On ne dispose donc pas de la commande complète montrée ensuite, de ses résultats ni des autres fonctionnalités éventuellement présentées. Le carnet conserve l'objectif, la comparaison avec le projet Maven et les premières manipulations disponibles, sans reconstruire un tutoriel qui ne figure pas dans l'extrait.
