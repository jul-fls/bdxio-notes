# Parlons de Bruno

**Florian Garcia · Vendredi 8 novembre 2024 · Amphi A**

## Un client pour explorer et tester les API

Florian Garcia présente Bruno, un client API comparable à des outils comme Postman. Il montre son utilisation dans un contexte de produit et commence par les requêtes que l’on veut envoyer, les paramètres et les informations nécessaires pour les exécuter.

## Lire la collection comme du code

La démonstration passe de l’interface aux fichiers. Une collection correspond à un dossier et les requêtes sont décrites dans le langage de fichiers Bru. On peut y retrouver la configuration et les scripts liés aux requêtes. Cette représentation permet d’examiner les changements et de les conserver avec les outils de gestion de versions habituels.

Le fichier devient un support partagé pour comprendre ce qu’une requête envoie. Les paramètres propres à un environnement ont aussi besoin d’être distingués des informations que l’équipe peut conserver et partager.

## Reprendre un parcours de vérification

Un client API aide à rejouer les mêmes opérations et à examiner les réponses. La collection donne de la valeur lorsqu’elle reste lisible pour les collègues : le nom des requêtes, leur organisation et les étapes nécessaires à leur exécution comptent.

Florian montre les possibilités de l’outil à partir du même ensemble, ce qui rend visible le lien entre les gestes dans l’interface et leur description dans les fichiers. On peut ainsi comprendre ce qui sera repris lors d’une prochaine utilisation.

## Ce que j’en garde

Créer une petite collection qui couvre un parcours utile du produit, puis vérifier qu’un collègue peut la reprendre avec ses paramètres. Le format de fichiers facilite le partage lorsque les secrets et les configurations locales sont gérés explicitement.
