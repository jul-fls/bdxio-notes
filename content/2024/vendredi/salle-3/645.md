# Partagez vos composants UI pour Android et iOS et visualisez les sur une simple page WEB ! 🪄

**Jonathan Lagneaux · Vendredi 8 novembre 2024 · Salle 3 (H1+H2)**

## Partager une bibliothèque de composants

Jonathan Lagneaux part du besoin d’une bibliothèque UI utilisable sur Android et iOS. Son équipe veut des composants natifs, faciles à tester et à documenter. Elle souhaite également les rendre visibles aux personnes qui n’ont pas nécessairement l’environnement de développement mobile sur leur poste.

## Une implémentation commune et des applications de démonstration

Le talk présente une approche avec Kotlin et Compose Multiplatform. La démonstration relie le code des composants aux points d’entrée qui permettent de les afficher sur les différentes plateformes. Jonathan montre notamment la configuration d’une application iOS et le passage par un contrôleur qui expose le contenu Compose.

L’enjeu est de partager une partie du travail tout en vérifiant ce qui se passe réellement sur Android et iOS. Une bibliothèque a besoin d’un endroit où l’on peut parcourir les variantes et observer les comportements. Ce catalogue devient aussi un support de discussion avec les autres membres de l’équipe.

## Rendre les composants visibles sur le web

Une page web permet de consulter le résultat sans installer deux applications mobiles. Elle peut servir à montrer les composants, partager les exemples et vérifier la documentation. Cette facilité de consultation fait partie du besoin initial : un composant existe aussi à travers la manière dont les personnes le découvrent et savent quand l’utiliser.

La démonstration montre le passage entre le code commun et les applications qui l’accueillent. Elle rend concret le partage sans faire disparaître la nécessité d’essayer les plateformes cibles.

## Ce que j’en garde

Pour une bibliothèque partagée, définir les comportements attendus et le parcours de consultation en même temps que l’implémentation. Un catalogue accessible rend le travail plus facile à examiner, tester et discuter.
